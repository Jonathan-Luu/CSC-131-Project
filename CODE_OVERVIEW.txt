NutritionTracker code overview
==============================

Scope
-----
This document explains the purpose of every tracked project/source/resource file and every Swift function, initializer, deinitializer, and important computed view/helper property in the application code.

Root files
----------

project.yml
- Purpose: XcodeGen project definition for the NutritionTracker iOS app. It defines the bundle identifier, Swift version, deployment target, app target, source folder, Info.plist path, and shared scheme.
- Functions: None.

README.md
- Purpose: High-level repository description and feature summary.
- Functions: None.

CODE_OVERVIEW.txt
- Purpose: This documentation file.
- Functions: None.

Databases/FoodData_Central_foundation_food_json_2025-12-18.json
- Purpose: Bundled USDA FoodData Central Foundation Foods database used for local food search and nutrient lookup.
- Functions: None.

NutritionTracker.xcodeproj/project.pbxproj
- Purpose: Xcode project graph. It lists source files, build phases, target settings, package references, and file group membership.
- Functions: None.

NutritionTracker.xcodeproj/project.xcworkspace/contents.xcworkspacedata
- Purpose: Xcode workspace metadata that points the workspace at the project.
- Functions: None.

NutritionTracker.xcodeproj/project.xcworkspace/xcshareddata/swiftpm/Package.resolved
- Purpose: Swift Package Manager lockfile for Firebase and related package versions.
- Functions: None.

NutritionTracker.xcodeproj/project.xcworkspace/xcuserdata/jonathan.xcuserdatad/UserInterfaceState.xcuserstate
- Purpose: Xcode user interface state file. This is user-specific IDE state, not app logic.
- Functions: None.

NutritionTracker.xcodeproj/xcshareddata/xcschemes/NutritionTracker.xcscheme
- Purpose: Shared Xcode scheme describing build/run/test/archive actions for the app target.
- Functions: None.

NutritionTracker/Info.plist
- Purpose: App Info.plist values used by iOS and Xcode.
- Functions: None.

NutritionTracker/GoogleService-Info.plist
- Purpose: Firebase app configuration, including project and bundle identifiers.
- Functions: None.

NutritionTracker/Assets.xcassets/Contents.json
- Purpose: Asset catalog metadata.
- Functions: None.

NutritionTracker/Assets.xcassets/AppIcon.appiconset/Contents.json
- Purpose: App icon asset metadata.
- Functions: None.

NutritionTracker/Assets.xcassets/AppIcon.appiconset/Untitled.png
- Purpose: App icon image asset.
- Functions: None.

Swift source files
------------------

NutritionTracker/NutritionTrackerApp.swift
- Purpose: Application entry point and Firebase startup configuration.
- AppDelegate.application(_:didFinishLaunchingWithOptions:) : Configures Firebase when the app launches and returns success to UIKit.
- NutritionTrackerApp.body                                  : Creates the app window and injects the shared NutritionStore, FoundationFoodDatabase, and AuthViewModel environment objects.

NutritionTracker/ContentView.swift
- Purpose: Root screen router. Shows the main tab interface when signed in and the login flow when signed out.
- ContentView.body : Builds the signed-in TabView or LoginView and keeps NutritionStore scoped to the current Firebase user.

NutritionTracker/AuthViewModel.swift
- Purpose: Firebase Authentication view model for sign-in, account creation, password reset, password changes, and sign-out.
- init()                                                       : Loads the current Firebase user and registers an auth-state listener.
- deinit                                                       : Removes the Firebase auth-state listener.
- isSignedIn                                                   : Returns whether a Firebase user is currently available.
- currentEmail                                                 : Returns the signed-in user's email or a fallback label.
- submit()                                                     : Validates email/password and either signs in or creates an account.
- signOut()                                                    : Signs the current Firebase user out and clears local password/error state.
- clearError()                                                 : Clears the current auth error message.
- sendPasswordReset(to:)                                       : Validates an email address and asks Firebase to send a reset email.
- changePassword(currentPassword:newPassword:confirmPassword:) : Validates password inputs, reauthenticates the user, and updates the Firebase password.
- describe(_:context:)                                         : Converts Firebase/Auth errors into user-facing messages based on operation context.

NutritionTracker/NutritionStore.swift
- Purpose: Central observable app store for goals, food entries, profile data, local persistence, Firebase Firestore sync, daily totals, history, and BMR calculation.
- init()                                     : Loads cached local state and scopes the store to the current Firebase user.
- setUser(uid:)                              : Switches all local/cache/cloud state to the supplied Firebase user id or resets to signed-out defaults.
- addFood(name:nutrients:)                   : Adds a logged food entry for the current user.
- deleteEntries(at:)                         : Deletes entries at List offsets.
- updateGoal(targets:)                       : Replaces the active nutrition goal targets.
- todaysTotals                               : Computes nutrient totals for entries logged today.
- historyByDay                               : Groups entries by day, computes daily totals, and marks whether daily goals were met.
- consistencyPercent                         : Computes the percent of logged days where goals were met.
- calculateBMR()                             : Calculates estimated daily energy need from profile values using sex, weight, height, age, and activity multiplier.
- totals(for:)                               : Sums nutrient dictionaries across a list of FoodEntry values.
- persist(_:)                                : Writes changed goal/entry/profile state to scoped UserDefaults and schedules a cloud write when eligible.
- loadGoal(forKey:)                          : Loads a NutritionGoal from scoped UserDefaults or returns the default goal.
- loadObject(forKey:defaultValue:)           : Generic scoped UserDefaults decode helper with a default-value fallback.
- saveObject(_:forKey:defaults:)             : Encodes a Codable value and writes it to UserDefaults.
- scopedKey(_:uid:)                          : Adds the user id suffix to a local persistence key when signed in.
- startFirestoreListener(uid:)               : Registers a Firestore snapshot listener and applies remote goal, entry, and profile data.
- scheduleCloudWrite()                       : Debounces and schedules a Firestore write for current local state.
- writeToCloud()                             : Serializes the current goal, entries, profile, and update timestamp to Firestore.
- handleFirestoreListenerError(_:)           : Handles listener errors, currently disabling cloud sync for auth/permission failures.
- disableCloudSyncForCurrentUser()           : Stops cloud sync, cancels pending writes, and removes the listener.
- isFirestoreAuthError(_:)                   : Detects Firestore permission/unauthenticated errors.
- profileIsNonDefault                        : Returns whether the profile differs from the default profile.
- ensureUserIsCurrent()                      : Rechecks Firebase's current user and resyncs store scoping if it changed.

NutritionTracker/NutritionDataModels.swift
- Purpose: Core app data types for goals, logged foods, daily history summaries, and user profile data.
- FoodEntry.init(id:name:nutrients:date:) : Creates a logged food entry and canonicalizes nutrient ids/values.
- FoodEntry.init(from:)                   : Decodes FoodEntry from the current nutrient dictionary format and canonicalizes nutrient ids/values.
- FoodEntry.encode(to:)                   : Encodes a FoodEntry using the current nutrient dictionary format.

NutritionTracker/NutrientCatalog.swift
- Purpose: Defines supported nutrient categories and the tracked USDA nutrient definitions, units, default targets, and maximum/minimum goal behavior.
- NutrientCatalog.definition(for:)          : Finds a tracked nutrient definition by USDA nutrient id.
- NutrientCatalog.defaultGoals              : Builds the default goal target dictionary for new installs.
- NutrientCatalog.goalsMet(totals:targets:) : Returns whether the supplied nutrient totals satisfy all active minimum goals.

NutritionTracker/NutrientNormalization.swift
- Purpose: Normalizes USDA nutrient aliases into the canonical nutrient ids used by the app.
- NutrientNormalization.canonicalizeNutrients(_:) : Fills canonical calories from USDA energy aliases, removes alias ids to avoid double-counting, and clamps negative carbohydrate values to zero.

NutritionTracker/FoundationFoodDatabase.swift
- Purpose: Loads the bundled USDA foundation foods database, exposes local search, and scales per-100g nutrient values.
- FDCFoodNutrient.resolvedAmount                   : Returns amount when available, otherwise median.
- FoundationFoodDatabase.init()                    : Starts loading the bundled database.
- FoundationFoodDatabase.search(_:)                : Tokenizes and ranks local food database matches for a query.
- FoundationFoodDatabase.scaledNutrients(_:grams:) : Scales per-100g nutrient values to a specific gram amount.
- FoundationFoodDatabase.load()                    : Reads, decodes, normalizes, and publishes foundation food items from the bundled JSON.

NutritionTracker/FoodBrowseCategories.swift
- Purpose: Shared tokenization and ranking logic for local USDA food search.
- FoodSearchQuery.tokens(from:)                                                   : Lowercases a query, splits into searchable tokens, drops short tokens, and canonicalizes plurals.
- FoodSearchQuery.normalizedText(from:)                                           : Produces a normalized string from search tokens.
- FoodSearchQuery.matchesAllTokens(description:fdcCategory:tokens:)               : Checks whether all query tokens are present in a food description or category.
- FoodSearchQuery.relevanceScore(description:fdcCategory:normalizedQuery:tokens:) : Scores search matches by phrase match, prefix match, category match, token hits, and description length.
- FoodSearchQuery.canonicalToken(_:)                                              : Applies simple plural normalization for more forgiving search.

NutritionTracker/DateCalendarExtensions.swift
- Purpose: Shared Date helpers for day/month normalization and comparisons.
- Date.startOfDay       : Returns the calendar start of the date's day.
- Date.startOfMonth     : Returns the first day of the date's month.
- Date.addingMonths(_:) : Adds calendar months to the date's month start.
- Date.isSameDay(as:)   : Returns whether two dates fall on the same calendar day.

NutritionTracker/AddFoodView.swift
- Purpose: Main Add Food tab. Supports manual nutrient entry and TheMealDB lookup.
- AddFoodView.body                      : Builds the segmented manual/MealDB interface and presents MealDBAddMealSheet.
- manualForm                            : Builds the manual food-name and nutrient-entry form.
- mealDBSection                         : Builds the TheMealDB search/results list and loading/error states.
- ensureManualFields()                  : Initializes manual entry fields for every tracked nutrient.
- addManual()                           : Validates manual food input, computes missing calories from macros when possible, adds the food, and clears the form.
- searchMealDB()                        : Searches TheMealDB by meal name and updates result/error state.
- selectMealDBMeal(_:)                  : Fetches full detail for a selected TheMealDB meal.
- computeCaloriesFromMacros(nutrients:) : Computes calories from protein, carbohydrates, and fat.

NutritionTracker/MealDBAddMealSheet.swift
- Purpose: Shared sheet for adding a TheMealDB meal from lookup or recommendations with estimated USDA nutrition.
- MealDBAddMealSheet.body          : Builds the meal detail, servings input, estimated nutrition preview, and add action.
- recomputePreview()               : Validates servings, estimates recipe nutrition, scales it to requested servings, and updates preview text.
- addToLog()                       : Validates servings, computes scaled nutrients, adds the meal to the log, and closes the sheet.
- format(_:)                       : Formats serving/count values compactly.
- nutritionPreviewText(for:)       : Builds preview text for active goal nutrients only.
- formattedNutrientAmount(_:unit:) : Formats a nutrient amount with appropriate precision and unit.

NutritionTracker/MealDBNutritionEstimator.swift
- Purpose: Estimates nutrition for TheMealDB recipes by matching ingredients to USDA foods and scaling by estimated grams.
- MealDBNutritionEstimator.estimateNutrients(detail:servings:foodDatabase:) : Matches each meal ingredient to USDA foods, scales nutrients by estimated ingredient grams, sums recipe totals, scales by servings, and fills calories if needed.
- computeCaloriesFromMacros(nutrients:)                                     : Computes calories from protein, carbohydrates, and fat when USDA calories are missing.
- sanitizeIngredientQuery(_:)                                               : Removes simple stop words from MealDB ingredient names before USDA search.
- estimateGrams(fromMeasure:)                                               : Parses a MealDB measure string into an estimated gram amount.
- parseQuantity(_:)                                                         : Local helper inside estimateGrams that parses whole numbers and fractions from quantity text.

NutritionTracker/TheMealDBClient.swift
- Purpose: Lightweight API client and response models for TheMealDB search, ingredient filtering, and detail lookup.
- Meal.id                                   : Exposes idMeal as Identifiable.id.
- MealDetail.id                             : Exposes idMeal as Identifiable.id.
- MealDetail.ingredientLines                : Formats decoded ingredient/measure pairs for display.
- NumberedMealDetailKey.init?(stringValue:) : Creates a dynamic coding key for numbered MealDB JSON keys.
- NumberedMealDetailKey.init?(intValue:)    : Creates a dynamic coding key from an integer value.
- MealDetail.init(from:)                    : Decodes base meal detail fields and converts numbered ingredient/measure JSON keys into an ingredients array.
- MealDetail.decodeIngredients(from:)       : Reads strIngredient1...20 and strMeasure1...20 JSON keys into Ingredient values.
- MealDetail.decodeString(from:key:)        : Safely decodes an optional string for a dynamic MealDB key.
- searchMealsByName(_:)                     : Calls TheMealDB search endpoint with a meal name query.
- filterMealsByIngredient(_:)               : Calls TheMealDB ingredient filter endpoint.
- lookupMealDetail(idMeal:)                 : Calls TheMealDB detail endpoint and returns the first meal detail.
- fetch(_:)                                 : Performs a URLSession request, validates HTTP success, and decodes JSON.

NutritionTracker/MealRecommendations.swift
- Purpose: View model and scoring logic for recommending TheMealDB meals based on unmet nutrition goals.
- refresh(store:foodDatabase:)                                         : Clears state, computes current deficits, guards loading/database state, and rebuilds recommendations.
- buildRecommendations(deficits:goalTargets:todayTotals:foodDatabase:) : Queries meals by proxy ingredients, estimates nutrition for candidates, scores them against deficits and overage penalties, and returns top recommendations.
- computeDeficits(goalTargets:todayTotals:)                            : Computes unmet minimum-goal nutrient deficits sorted by percent deficit.
- deficitWeights(deficits:targets:)                                    : Normalizes deficit percentages into weights for scoring.
- proxyIngredients(forNutrientId:)                                     : Maps a nutrient id to ingredient queries likely to provide that nutrient.
- divideNutrients(_:by:)                                               : Divides all nutrient values by a serving divisor.
- estimateServingsPerRecipe(fromRecipeTotals:)                         : Estimates recipe yield from total calories and clamps it to a reasonable serving count.

NutritionTracker/RecommendationsView.swift
- Purpose: Recommendations screen showing missing goals, recommended meals, refresh/loading state, and add-meal lookup.
- RecommendationsView.body  : Builds the recommendations list, refresh toolbar, lookup loading overlay, initial refresh task, errors, and meal-add sheet.
- recommendationsLoadingRow : Builds the centered recommendations loading row.
- openLookup(for:)          : Fetches full meal detail for a selected recommendation and opens the add sheet.
- summaryLine(_:)           : Formats a short nutrient summary for a recommendation.
- focusLine(_:)             : Formats the nutrient names a recommendation was chosen to help with.
- format(_:)                : Formats deficit numbers.

NutritionTracker/DashboardView.swift
- Purpose: Main nutrition dashboard showing today's progress for active goals and optional untracked nutrient totals.
- totals                          : Returns today's nutrient totals from NutritionStore.
- DashboardView.body              : Builds sections for active goal nutrients and an expandable untracked nutrients area.
- nutrientRow(def:value:)         : Builds a nutrient row with amount text and progress/limit styling.
- format(_:)                      : Formats numeric nutrient amounts.
- normalizedProgress(value:goal:) : Clamps progress to the 0...1 range.
- hasDailyGoal(for:)              : Returns whether a nutrient has an active daily target.
- additionalDefinitions(in:)      : Returns untracked nutrients for a category.
- additionalCategoryBinding(for:) : Builds an expansion binding for an untracked nutrient category.
- untrackedDefinitions            : Returns all tracked nutrients without active daily goals.

NutritionTracker/GoalsView.swift
- Purpose: Goals tab for editing, removing, saving, and navigating to add daily nutrition goals.
- GoalsView.body    : Builds the active-goal form, save button, Add Goal link, and validation message.
- activeDefinitions : Returns tracked nutrient definitions with active targets.
- hasUnsavedChanges : Compares draft goal values with persisted goal targets.
- goalRow(def:)     : Builds one editable goal row with a remove button.
- syncFromStore()   : Synchronizes draft text fields from NutritionStore goals.
- removeGoal(_:)    : Sets a goal target to zero and removes it from the draft.
- saveGoalChanges() : Validates draft targets and writes them to NutritionStore.
- formatGoal(_:)    : Formats goal values for text fields.

NutritionTracker/AddGoalView.swift
- Purpose: Screen for searching/selecting nutrients that do not already have active goals and saving a new target.
- AddGoalView.body              : Builds the searchable nutrient picker and target-entry alert.
- nutrientSelectionSection      : Builds the nutrient selection section and empty state.
- categoryDisclosureGroup(for:) : Builds a category disclosure group when matching nutrients exist.
- nutrientRow(for:)             : Builds a selectable nutrient row.
- selectedDefinition            : Resolves the currently selected nutrient definition.
- activeGoalIds                 : Returns nutrient ids with active goal targets.
- availableDefinitions          : Returns tracked nutrients that do not already have active goals.
- filteredAvailableDefinitions  : Filters available definitions by search text.
- emptyStateMessage             : Returns the correct empty/search result message.
- filteredDefinitions(in:)      : Returns filtered nutrient definitions for one category.
- expansionBinding(for:)        : Builds a category expansion binding.
- select(_:)                    : Selects a nutrient and opens the goal target alert.
- saveGoal()                    : Validates the target amount and writes the new goal into NutritionStore.
- alertMessage(for:)            : Builds alert helper text plus validation error text.
- expandRelevantCategories()    : Expands categories containing search matches.
- formatGoal(_:)                : Formats default goal values for the alert text field.

NutritionTracker/HistoryView.swift
- Purpose: History tab with calendar navigation, per-day drilldown, all-entry access, and goal consistency summary.
- HistoryView.body                   : Builds the calendar, all entries link, empty/help text, consistency tracker, day navigation, and month picker sheet.
- entryDaysInLog                     : Returns dates that have logged entries.
- goalMetDaysInLog                   : Returns dates whose logged totals met active goals.
- metGoalDayCount                    : Counts logged days that met active goals.
- hasActiveGoals                     : Returns whether any goal target is active.
- today                              : Returns today's start-of-day date.
- minMonth                           : Returns the earliest supported history month.
- maxMonth                           : Returns the current month.
- ConsistencyTrackerView.progress    : Converts a percentage to 0...1 progress.
- ConsistencyTrackerView.body        : Builds the goal consistency card and progress bar.
- ConsistencyTrackerView.percentText : Formats the consistency percentage.
- ConsistencyTrackerView.summaryText : Builds explanatory text for goal consistency state.
- MonthPickerSheet.body              : Builds the month picker form and Cancel/Go toolbar actions.
- MonthPickerSheet.monthOptions      : Builds the list of selectable months between min and max.
- MonthPickerSheet.monthLabel(_:)    : Formats a month label.
- MonthPickerSheet.clampMonth(_:)    : Clamps a date to the supported month range.

- leadingBlankItems                                      : Builds stable identifiable blank cells before the first day.
